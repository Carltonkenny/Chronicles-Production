# 🎬 Phase 5: Post-Production & Assembly (Week 11-12)

## Objective
Implement Editor → Sound Designer → Colorist → FFmpeg Assembler pipeline. Take raw video clips and produce a polished MP4 film with narration, music, sound effects, color grading, transitions, and credits.

### Sound Designer Agent

```
Responsibilities:
  1. NARRATION: Generate via Amazon Polly
     - SSML with prosody for expressive reading
     - Culture-appropriate voice (see voice map)
     - Per-scene timing aligned to Editor's timeline

  2. MUSIC: Generate via Suno/Udio
     - Per emotional beat (wonder, tension, obsession, loss)
     - 30-90 second segments, crossfaded
     - Instrumental only (no vocals in background)
     - Culture-appropriate instruments

  3. SFX: Procure/generate ambient sounds
     - Per location: river (water flow, ice crack), forge (fire, hammer)
     - Low in mix (-18dB relative to narration)
     - Looped if scene longer than SFX duration
```

### Colorist Agent

```
Input:
  - Visual Bible color palette
  - Video clip URLs (or sample frames)
  - Scene emotional arc

Output:
  - ColorGradingSpec:
    {
      "lut": "warm_historical",  // Base LUT for entire film
      "adjustments": [
        {
          "scene_index": 0,
          "temperature": 5500,       // Dawn = cool
          "tint": -5,
          "contrast": 1.1,
          "saturation": 0.9,
          "vignette": 0.2
        },
        {
          "scene_index": 1,
          "temperature": 3200,       // Forge fire = very warm
          "tint": 10,
          "contrast": 1.3,
          "saturation": 0.8,
          "vignette": 0.3
        }
      ]
    }

DO:
  ✅ Consistent color across all scenes (no jarring jumps)
  ✅ Warm scenes for hope/wonder/love
  ✅ Cool scenes for loss/despair/conflict
  ✅ Match Visual Bible palette

DON'T:
  ❌ Apply different LUTs to consecutive scenes
  ❌ Over-saturate
  ❌ Ignore time-of-day lighting consistency
```

## FFmpeg Assembly Commands

```bash
# Step 1: Create concat file
# file 'scene_1.mp4'
# file 'scene_2.mp4'
# ...

# Step 2: Concatenate with transitions
ffmpeg -f concat -safe 0 -i concat.txt \
       -vf "xfade=transition=fade:duration=1:offset=7" \
       -c:v libx264 -preset medium -crf 23 \
       temp_video.mp4

# Step 3: Generate narration (separate, via Polly API)
# Output: narration.wav

# Step 4: Generate music (separate, via Suno API)
# Output: music.wav

# Step 5: Mix audio tracks
ffmpeg -i narration.wav -i music.wav -i sfx.wav \
       -filter_complex "[1:a]volume=0.3[music];[2:a]volume=0.15[sfx];[0:a][music][sfx]amix=inputs=3:duration=first" \
       mixed_audio.wav

# Step 6: Overlay audio onto video
ffmpeg -i temp_video.mp4 -i mixed_audio.wav \
       -c:v copy -c:a aac -b:a 192k \
       temp_with_audio.mp4

# Step 7: Apply color grading
ffmpeg -i temp_with_audio.mp4 \
       -vf "eq=brightness=0.0:contrast=1.1:saturation=0.9, \
            colorbalance=rs=0.1:gs=-0.1:bs=-0.2, \
            vignette=PI/4" \
       temp_graded.mp4

# Step 8: Add title card
ffmpeg -i temp_graded.mp4 \
       -vf "drawtext=text='THE STAR FORGE':fontfile=cinzel.ttf: \
            fontsize=48:fontcolor=white:x=(w-text_w)/2:y=(h-text_h)/2: \
            enable='between(t,0,3)'" \
       temp_titled.mp4

# Step 9: Add credits
ffmpeg -i temp_titled.mp4 \
       -vf "drawtext=text='Generated by Chronicles Production': \
            fontsize=14:fontcolor=white@0.7: \
            x=(w-text_w)/2:y=h-th-40: \
            enable='between(t,67,72)'" \
       final.mp4

# Step 10: Encode to optimal size
ffmpeg -i final.mp4 \
       -c:v libx264 -preset slow -crf 23 \
       -c:a aac -b:a 128k \
       -movflags +faststart \
       chronicles_a3f2b8c9.mp4
```
